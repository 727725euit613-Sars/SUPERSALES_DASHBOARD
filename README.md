# Superstore Sales Analysis – Excel Project

## Project Overview
This project analyses Superstore sales data using Microsoft Excel to identify business trends, product performance and regional sales patterns.

## Tools Used
- Microsoft Excel
- Excel Formulas
- Data Cleaning
- PivotTables
- PivotCharts
- Slicers and Dashboard

## Project Workflow
1. Imported the Superstore dataset.
2. Cleaned and validated the data.
3. Analysed sales using Excel formulas.
4. Created PivotTables for business analysis.
5. Developed an interactive sales dashboard.
6. Identified five business insights.

## Business Questions
- What is the total revenue?
- Which region generates the highest sales?
- Which category performs best?
- Which month has the highest sales?
- Which products generate the most revenue?
